# Функциональные требования к веб-приложению бронирования переговорных комнат с интеграцией Google Календаря
## Стек технологий:
	Backend:
        1) C#
        2) ASP.NET Core 8.0
        3) PostgreSQL
    Frontend
        4) React(JavaScript)
## При использовании приложения пользователю будут доступны следующие функции:
    1) Роли пользователей
    2) Просмотр переговорных комнат
    3) Просмотр бронирований
    4) Создание бронирования с уакзанием:
        - Названия встречи
	- Описанием встречи
        - Даты и времени(начало/оканчание)
        - Организатора встречи
	- Указанием переговорной комнаты
    5) Добавления оборудования комнате
    6) Добавление пользователей с указанием:
	- Имя пользователя 
 	- Email пользователя
	- Пароль (любые символы, количество символов от 1 до 250)
        - Выбор роли (Админ, пользователь)
    7) Добавление участников в встречи с указанием:
    	- Пользователя
        - Комнаты
        - Статуса 
## Функциональные особенности программы:
    Интеграция с Google Calendar API. 
    В бд будет таблица гостей и админов с флагом о статусе, 
    таблица комнат и таблица бронированных комнат пользователей.
